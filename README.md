- Ukraine says it sank the Russian corvette Merkury off Benghazi.
- Plus: tanker attacks at a record high in the Strait of Hormuz, NATO's emergency session after Russian missiles entered Poland, 15 killed in strikes near Kyiv, COP31 collapsing with no deal, Democrats' 258-seat House majority, and 24 dead in an Indonesian factory fire.

`main.ts` (Node, standard library only) copies `entry.png` to the output directory. The image is 1024×1024 and under 1 MiB; running the program twice writes identical bytes.

Sources: Reuters, CNN, AP, WSJ — 23 November 2026.
